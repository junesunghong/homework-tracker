## 2. 기술 선택과 이유

| 선택 | 이유 | 버린 대안 |

| 파이썬 표준 라이브러리 서버 | Windows·macOS·라즈베리파이·안드로이드(Termux) 어디서나 설치 없이 실행 | Node/Flask(패키지 설치 필요), Firebase(외부 클라우드 의존·가족 데이터 외부 반출) |

## 3. 데이터 모델

```text
meta(key, value)                 family_name, import_key, rev(변경 번호), schema_version
users(id, role, name, pin_hash, entry_year, color, active)
sessions(token_hash, user_id, device, created_at, last_seen)
subjects(id, name, sort)
routines(id, child_id, title, subject, kind, weekdays "1,3,5", active)
tasks(id, child_id, title, subject, kind, memo, due_date, status, progress,
      source(manual|routine|sms|...), source_text, routine_id,
      created_by, created_at, updated_at, submitted_at, completed_at, verified_by)
task_logs(id, task_id, user_id, action, note, progress, at)
```

- `kind`: homework(숙제) · study(학습) · prepare(준비물) · exam(시험) · etc
- 모든 쓰기 동작은 `rev` 를 1 올린다. 클라이언트는 `GET /api/rev` 만 보고 변경 시 전체 재조회.
- 루틴은 할 일 조회 시 **오늘 날짜분만** 생성한다. `(routine_id, due_date)` 유일 인덱스로 중복 방지.

## 4. 상태 전이

```text
          accept(부모)
 inbox ──────────────▶ todo ──start──▶ doing ──submit──▶ submitted ──approve(부모)──▶ done
                         │               ▲  ▲                │                          │
                         └──progress─────┘  └──reject(부모)───┤                          │
                                            └──cancel─────────┘                          │
                         todo/doing ──approve(부모, 바로 완료)──────────────────────────▶ │
                                            ◀────────────────reopen(부모)────────────────┘
```

전이표는 `server.py` 의 `App.TRANSITIONS` 한 곳에 있다. 허용되지 않은 전이는 409.

## 7. 외부 가져오기 확장 계획

1단계(v1.0.0, 완료): 수신 API·원문 보관·날짜/과목 추정·부모 확인 큐.

2단계(예정) — 수집기 후보:

| 출처 | 방법 | 비고 |
|---|---|---|
| 문자(SMS) | 안드로이드 문자 전달 앱의 Webhook, 또는 Tasker/MacroDroid "문자 수신 → HTTP POST" | 아이폰은 단축어 자동화의 메시지 트리거로 가능하나 제약 큼 |
| 학교 알림앱 | 안드로이드 알림 감지(Tasker/MacroDroid) → HTTP POST | 앱 내부 API 직접 호출은 약관·인증 문제로 비권장 |
| 학원 문자 | SMS 와 동일 | 발신번호로 자녀 자동 지정(서버에 번호→자녀 매핑 추가 예정) |

추정 규칙(`guess_title/guess_due/guess_subject`)은 단순 정규식이다. 오인식은 inbox 단계에서 부모가 고친다.

## 8. 기간 요약 (v1.1.0)

부모 화면(자녀별 카드)과 자녀 화면(자기 카드) 상단에 표시한다. 기간 선택은 기기별로 기억한다.

| 기간 | 범위 |
|---|---|
| 오늘 | 오늘 마감 |
| 주말까지 | 오늘 ~ 이번 주 일요일 마감. "월요일 마감 포함" 체크 시 다음 월요일까지 |
| 이번 주 | 이번 주 월요일 ~ 일요일 마감 |

집계 규칙:

- 대상 = 기간 안에 마감인 할 일 + 마감이 지났는데 아직 완료가 아닌 할 일. 마감 없는 할 일과 `inbox` 는 제외.
- **완료** = `done`(부모 확인까지 끝남). **확인 대기** = `submitted`. **남음** = `todo`·`doing`. **마감 지남** = 남음 중 마감이 오늘 이전.
- 표시 문구: 대상 0개 → "할 일이 없어요" / 남음·확인 대기 0 → "🎉 모두 완료" / 남음 0·확인 대기 있음 → "다 했어요 · 부모 확인 N개 남음" / 그 외 → "N개 남음" + 남은 일 제목 3개.
- 클라이언트가 이미 받은 데이터(진행 중 전체 + 최근 30일 완료)로 계산한다. 서버 변경 없음.

반려 표시: 할 일 목록 API 가 마지막 상태 결정 기록(`submit/reject/approve/reopen/cancel` 중 최신)의 동작과 메모를 `last_decision`·`last_note` 로 함께 내려준다. 최신이 `reject` 이면 카드에 "↩ 다시 하기: 메모"를 표시한다. 반려 시 진행률은 50% 이하로 낮춘다.

## 9. 안드로이드 앱 (v1.2.0)

| 항목 | 내용 |
|---|---|
| 구성 | Java, AndroidX 없음, minSdk 26 / targetSdk 35. AGP 8.7.3 + Gradle 9.7.1 (gonggi-referee 와 같은 조합) |
| 화면 | WebView 가 서버의 웹 화면을 띄운다. UA 에 `HomeworkApp/<버전>`, `window.HomeworkApp` 다리(앱 버전·앱 설정·업데이트 확인·파일 저장) |
| 역할 선택 | `SetupActivity` — 접속 기기(자동 찾기/주소 입력, `/api/status` 로 확인) 또는 서버 |
| 서버 모드 | `ServerService`(포그라운드, specialUse) 가 Chaquopy 로 `server.run_embedded()` 호출. 화면 파일은 assets/web → 앱 폴더로 복사. Wake·Wi-Fi·Multicast lock |
| 자동 시작 | `BootReceiver` — 부팅 완료·앱 업데이트(MY_PACKAGE_REPLACED) 때 서버 역할이면 서비스 시작 |
| 업데이트 | `Updater` — 6시간마다(앱 열 때) `/app/version.json` 확인 → 새 버전이면 APK 를 받아 `PackageInstaller` 세션 설치. 서버 기기는 자기 APK(`sourceDir`)를 배포 |
| 서명 | `HW_KS_FILE`·`HW_KS_PASS` (Secrets 또는 ~/.gradle). 태그 릴리스는 키 필수 |
| 버전 | `server.py` 의 `APP_VERSION` 이 유일한 원천. versionCode = 주×10000 + 부×100 + 수 |

업데이트 흐름:

```text
릴리스 APK ──(수동 설치)──▶ 서버 기기 앱 ──/app/homework-tracker.apk──▶ 접속 기기 앱 (확인 후 설치)
                                └─ 내장 서버의 화면(static)도 함께 새 버전
```

## 10. 남은 과제

- 발신번호 → 자녀 자동 매핑, 키워드 필터(숙제·과제·준비물만 수집)

- 서버 기기 교체 시 데이터 이전(백업 JSON 가져오기)

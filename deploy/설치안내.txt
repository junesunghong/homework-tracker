숙제 체크 {버전} — 설치 안내

집 와이파이 안에서 자녀 숙제를 등록·확인하는 앱입니다.
가족 기기 중 1대는 「서버」, 나머지는 「접속 기기」로 씁니다. 같은 앱 하나로 둘 다 됩니다.

  homework-tracker-{버전}.apk          안드로이드 탭·휴대폰에 설치하는 앱
  homework-tracker-server-{버전}.zip   (선택) PC 를 서버로 쓸 때


1. 서버 기기에 설치하기 (집에 늘 켜 두는 안드로이드 1대)
--------------------------------------------------------
  1) APK 파일을 기기로 옮깁니다.
     GitHub 에 로그인한 브라우저에서 바로 받거나, 구글 드라이브·USB 케이블을 씁니다.
     (Gmail 은 APK 첨부를 막고, 메신저도 막는 경우가 있습니다)
  2) 파일을 누릅니다.
  3) "출처를 알 수 없는 앱" 설치를 허용하겠느냐고 물으면
     [설정] → 이 출처 허용을 켜고 돌아옵니다.
  4) [설치]를 누릅니다.
     Play 프로텍트가 "알 수 없는 앱"이라고 경고하면
     [세부정보 더보기] → [무시하고 설치]를 누릅니다.
     (Play 스토어를 거치지 않은 앱이라 나오는 경고입니다)
     안드로이드 7 에서는 3)의 질문 없이 설치가 막히는데,
     [설정] → [보안] → "알 수 없는 출처"를 켜고 다시 누르면 됩니다.
  5) 앱을 열고 [이 기기를 서버로 사용] → 알림 허용 → 배터리 최적화 해제(허용).
     충전기에 꽂아 두세요. 화면이 뜨면 가족 그룹(부모·자녀 이름, PIN)을 만듭니다.


2. 자녀 탭 · 부모 휴대폰에 설치하기 (접속 기기)
-----------------------------------------------
  1) 서버 기기 앱에서 ⚙ 설정 → 「안드로이드 앱」에 나온 주소를 확인합니다.
     예) http://192.168.0.23:8080/app/homework-tracker.apk
  2) 같은 와이파이에 연결된 탭·휴대폰의 브라우저(크롬)에 그 주소를 입력해 받습니다.
  3) 위 1번의 2)~4)와 같이 설치합니다.
  4) 앱을 열고 [서버 자동으로 찾기] → 나온 서버를 눌러 연결합니다.
     찾지 못하면 주소(예: 192.168.0.23:8080)를 직접 입력합니다.

  · 다음부터는 서버 기기의 앱만 새 버전으로 바꾸면,
    다른 기기는 앱을 열 때 "새 버전" 창이 떠서 [업데이트] 한 번이면 됩니다.
  · 아이폰·아이패드는 앱 없이 사파리에서 같은 주소(http://…:8080)로 쓰면 됩니다.


3. 설치가 안 될 때
------------------
  "앱이 설치되지 않았습니다" / "기존 패키지와 충돌"
      예전에 서명이 다른 시험용 APK 를 설치한 경우입니다. 앱을 삭제한 뒤 다시 설치하세요.
      (접속 기기는 지워도 데이터가 서버에 있어 괜찮습니다.
       서버 기기는 먼저 ⚙ 설정 → 백업 → JSON 내려받기로 백업하세요)
  "패키지를 파싱하는 중 문제가 발생했습니다"
      파일이 덜 받아졌거나, 안드로이드 7 미만 기기입니다. 다시 받아 보고, 안 되면 기기 버전을 확인하세요.
  설치 버튼이 회색이거나 눌리지 않음
      Play 프로텍트 창이 뒤에 떠 있는지 확인하고 [무시하고 설치]를 누르세요.
  서버를 못 찾음
      같은 와이파이인지(게스트 와이파이 X), 서버 기기 알림에 "서버 실행 중"이 보이는지 확인하세요.

  · 안드로이드 7.0 이상에서 동작합니다.
  · 숙제 데이터는 서버 기기 안에만 저장됩니다.
